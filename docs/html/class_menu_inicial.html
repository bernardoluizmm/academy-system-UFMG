Descrição detalhada

Representa o menu de entrada exibido ao iniciar a aplicação.

Herda da classe abstrata Menu e oferece ao usuário as opções de carregar um perfil salvo anteriormente, iniciar o cadastro de um novo estudante ou encerrar a execução do programa.
