◆ exibirResumoAcademico()

void MenuPrincipal::exibirResumoAcademico ( ) const
private

Exibe o resumo academico do estudante.

Mostra nome, curso, semestre de ingresso e semestre atual, os indicadores de rendimento (NSG parcial, medio e global) e o progresso de integralizacao do curso (percentual e horas cumpridas/exigidas em obrigatorias, optativas, formacao livre e total).

◆ exibirTabelaGeralDisciplinas()

void MenuPrincipal::exibirTabelaGeralDisciplinas ( ) const
private

Exibe a tabela geral das disciplinas do semestre atual.

Para cada disciplina mostra ID, nome, pontos distribuidos, nota obtida, media parcial, conceito parcial, faltas e maximo de faltas. Exibe um aviso se nao houver disciplinas.

◆ processarEntrada()

Menu * MenuPrincipal::processarEntrada ( )
overridevirtual

Le a opcao do usuario e decide a transicao de tela.

Opcoes: 1 a 4 abrem os menus de disciplinas, atividades, frequencia e detalhamento; 5 consolida o semestre atual e inicia o proximo; 0 salva o perfil e encerra.

Retorna
Ponteiro para o novo menu a empilhar (opcoes 1 a 4), this ao consolidar o semestre (opcao 5) ou nullptr ao salvar e sair (opcao 0).
