Descrição detalhada

Gerencia as atividades avaliativas de uma disciplina e calcula totais, média e conceito parciais.

As atividades são mantidas ordenadas da data mais antiga para a mais recente. Os cálculos "parciais" consideram apenas as atividades já concluídas.

Adiciona uma atividade com todos os dados informados (por exemplo, ao carregar de arquivo).

O contador interno é atualizado para ficar acima de id, quando necessário, e a lista é reordenada por data após a inserção.
