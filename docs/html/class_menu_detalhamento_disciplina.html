void MenuDetalhamentoDisciplina::exibirDetalhamentoDisciplina ( const Disciplina & disciplina) const
private

Exibe o detalhamento completo de uma disciplina.

Mostra os dados cadastrais (codigo, turma, professor, sala, carga horaria, tipo e horario), a tabela de atividades avaliativas e uma linha de totais (valor concluido, nota obtida, conceito e media parciais).

Parâmetros
disciplinaDisciplina a ser detalhada.
