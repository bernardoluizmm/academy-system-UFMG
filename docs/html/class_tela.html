Descrição detalhada

Classe base abstrata para todas as telas do sistema.

Define a interface polimórfica (executar() e getNome()) e fornece helpers de I/O em terminal (cout/cin) compartilhados por herança.

A Tela não é dona do Estudante: apenas mantém uma referência a ele.
