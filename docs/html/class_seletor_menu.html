Descrição detalhada

Controla o laco principal do programa utilizando uma pilha de telas (LIFO).

Totalmente desacoplado de Estudante e GerenciadorArquivo: gerencia apenas objetos polimorficos do tipo Menu*. Empilha novas telas ao avancar e desempilha ao receber nullptr.
