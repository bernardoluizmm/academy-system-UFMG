Descrição detalhada

Classe base abstrata das telas de interacao via terminal.

Totalmente desacoplada das classes de dominio: oferece apenas o contrato polimorfico de exibicao e transicao de telas (para uso na pilha do SeletorMenu) e os utilitarios de leitura e sanitizacao de entrada.

◆ substituirPilhaAoTransicionar()

bool Menu::substituirPilhaAoTransicionar ( ) const
virtual

Indica ao SeletorMenu se, ao avancar para uma nova tela, a pilha anterior deve ser substituida.

Retorna
true se a nova tela deve substituir toda a pilha anterior (ex.: entrada no MenuPrincipal); false (padrao) para apenas empilhar a nova tela sobre a atual.

Reimplementado por MenuCadastroUsuario e MenuCarregarUsuario.
