◆ calcularDiasMaximosFalta()

int CalculadorMaxFaltas::calcularDiasMaximosFalta ( int cargaHorariaHoras,
int duracaoAulaMinutos )
static

Calcula o número máximo de encontros (dias) em que o estudante pode faltar.

O limite corresponde a 25% da carga horária (em horas-aula de 50 minutos), dividido pela quantidade de horas-aula de cada encontro:

  • limite de horas-aula = cargaHorariaHoras / 4;
  • horas-aula por encontro = duracaoAulaMinutos / 50 (divisão inteira);
  • resultado = limite de horas-aula / horas-aula por encontro (divisão inteira).
Parâmetros
cargaHorariaHorasCarga horária total da disciplina. Deve ser maior que zero e divisível por 15.
duracaoAulaMinutosDuração de cada encontro, em minutos. Deve ser de, no mínimo, 50.
Retorna
Quantidade máxima de faltas (encontros) permitida.
Exceções
std::invalid_argumentSe a carga horária for inválida (<= 0 ou não divisível por 15) ou se a duração da aula for menor que 50 minutos.
