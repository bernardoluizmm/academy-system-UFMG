Descrição detalhada

Classe utilitária (sem estado) para persistência do perfil em arquivo .txt.

Serializa e desserializa o perfil completo do estudante em um arquivo de texto tabular, com campos separados por ponto e vírgula (;). Erros são sinalizados por retorno bool (true = sucesso, false = erro).
